How the DQM agent thinks

An agent (Claude) plays the role of a particle-detector data quality shift worker: given a batch of collision data, it decides which statistical checks to run, weighs the evidence, and writes a verdict -- the same judgment a human shift worker would make, automated. This page has no live API calls -- it replays a real run's actual decisions, recorded exactly as they happened.
